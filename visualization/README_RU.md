# Визуализация Reality Ontology 3.1

## Файлы

- `ontology_overview.graphml` — общая обзорная схема: базовый класс, основные и контекстные классы, вычисляемый класс и основной цикл.
- `ontology_class_hierarchy.graphml` — подробная иерархия классов с количеством свойств, методов и ограничений.
- `ontology_relations_detailed.graphml` — все явно заданные в исходной онтологии группы связей. На ребре указаны идентификатор группы, кардинальность и английские имена типов связей.
- `ontology_needs_detailed.graphml` — иерархия `NeedType → Subcategory → NeedInstance` и 12 типов потребностей верхнего уровня.
- `generate_graphml.py` — воспроизводимый генератор схем из `ontology_master_v3_1.json`.
- `validate_graphml.py` — проверка XML-структуры и точного покрытия объявленных связей.
- `SOURCE_COMPARISON_RU.md` — результат сопоставления JSON/YAML с русскоязычным PDF.

Цвета различают базовый класс, основные классы, контекстные слои, потребности и вычисляемый класс `Subject`. Треугольная стрелка означает наследование; обычная стрелка — явно объявленную связь; пунктир — классификацию типа потребности.

## Как открыть в yEd

1. Установите **yEd Graph Editor**.
2. Выберите **File → Open** и откройте нужный файл `.graphml` из этой папки.
3. Для автоматической перекладки выберите **Layout → Organic** (для обзорной схемы и связей) либо **Layout → Hierarchical** (для иерархий).
4. Если подписи пересекаются, примените **Layout → Labeling → Generic Labeling** и сохраните результат под новым именем, чтобы не менять поставляемую схему.

## Источники и ограничения

Структурным источником схем служит `ontology_master_v3_1.json`; он сопоставлен с `ontology_master_v3_1.yaml`, и документы эквивалентны по данным. Онтологический раздел предоставленного русскоязычного PDF `ru_quantitative_labour_model_capital_debt_markets_V6_4.pdf` также сопоставлен с этими файлами; подробности приведены в `SOURCE_COMPARISON_RU.md`. PDF подтверждает базовые понятия, но не содержит полного машиночитаемого перечня связей, поэтому рёбра берутся только из JSON/YAML. Новые предметные связи не добавлялись.

## Повторная генерация и проверка

Из корня репозитория выполните:

```bash
python3 visualization/generate_graphml.py
python3 visualization/validate_graphml.py
```
