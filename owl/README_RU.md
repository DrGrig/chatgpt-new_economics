# Reality Ontology 3.1 в OWL

Файл `ontology.owl` записан в формате **RDF/XML** и предназначен для открытия в Protégé. Он построен непосредственно по `ontology_master_v3_1.json` и эквивалентному ему `ontology_master_v3_1.yaml`; онтологический раздел предоставленного PDF использован для смысловой сверки. Схемы из `visualization` не являются источником аксиом.

## Открытие в Protégé

1. Запустите Protégé 5.x.
2. Выберите **File → Open…**.
3. Откройте `owl/ontology.owl`.
4. Основные классы доступны на вкладке **Classes**, связи — на **Object properties**, явно типизированные скалярные поля — на **Data properties**, а поля с неуказанным исходным типом — на **Annotation properties**.
5. Чтобы не потерять исходное RDF/XML-представление, сохраняйте рабочие изменения в отдельный файл.

Подробное соответствие исходной модели, принятые правила переноса, расхождения источников и ограничения OWL описаны в `MAPPING_RU.md`.

## Фактически выполненные проверки

- синтаксический разбор RDF/XML стандартным модулем Python `xml.etree.ElementTree`;
- проверка уникальности всех `rdf:about` и разрешимости ссылок на классы в `rdfs:subClassOf`, `rdfs:domain` и `rdfs:range`;
- проверка наличия 11 исходных фундаментальных классов, вычисляемого `Subject`, 12 верхнеуровневых типов потребностей и всех 26 подробных пар источник–цель;
- проверка эквивалентности данных JSON и YAML;
- проверка, что исходные файлы и папка `visualization` не изменены.

OWL API, ROBOT, HermiT, Pellet или другой DL-ризонер в окружении не доступны. Поэтому автоматическая классификация и проверка логической непротиворечивости ризонером **не выполнялись**. В онтологию намеренно не добавлены дизъюнктность, кардинальности, функциональность свойств или ограничения значений, которых нет в источниках.
